To run the project follow the steps 
1. download java 21 LTS version , node.js v22.17.1 version , maven 3.9.11 version
2. clone using the command "git clone -b dev https://github.com/Hiten303/URL-Shortner.git"
3. go to frontend folder using the command "cd URL-Shortner/url-shortner-frontend"
4. run the command  "npm install && npm run dev" (if node.js is not installed) else run "npm run dev"
5. go to root folder using the command "cd .."
6. now run "./run_dev.sh"
7. access the project on your browser by typing "http://localhost:3000/"
